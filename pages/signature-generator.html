Gmail — Google Workspace Empfohlen

Wir arbeiten unternehmensübergreifend mit Google Workspace — Gmail ist daher die empfohlene Plattform. Mit Workspace stehen zudem die KI-Funktionen von Gemini direkt im Posteingang zur Verfügung: E-Mails zusammenfassen, Antworten vorschlagen und Inhalte generieren — ohne den Browser zu verlassen.

  1. Auf „Signatur kopieren" klicken.
  2. Gmail öffnen → Einstellungen (Zahnrad → „Alle Einstellungen anzeigen").
  3. Tab „Allgemein" → Abschnitt „Signatur" → „Neu erstellen".
  4. Namen vergeben → in das Textfeld einfügen (Cmd+V / Strg+V).
  5. Unter „Standardwerte" die neue Signatur für neue E-Mails und Antworten auswählen.
  6. Ganz unten auf „Änderungen speichern" klicken.

Outlook (Desktop)

  1. Auf „Signatur kopieren" klicken.
  2. Neue E-Mail erstellen → im Menüband auf „Signatur" → „Signaturen..." klicken.
  3. „Neu" → Namen vergeben → in das Textfeld einfügen (Strg+V).
  4. Rechts unter „Standardsignatur" für neue und weitergeleitete Mails auswählen.
  5. „OK" klicken.

Apple Mail (macOS)

  1. Auf „Signatur kopieren" klicken.
  2. Mail-App → Menü „Mail" → „Einstellungen..." → Tab „Signaturen".
  3. E-Mail-Konto auswählen → + → Signatur einfügen (Cmd+V).
  4. Wichtig: Haken bei „Immer meine Standardschrift verwenden" entfernen.
  5. Signaturnamen per Drag & Drop auf das E-Mail-Konto (linke Spalte) ziehen.

Hinweis: Mobile Apps

Die Gmail-App auf iOS/Android unterstützt keine HTML-Signaturen. Die Signatur funktioniert zuverlässig im Browser und in Desktop-Clients. Die mobile Signatur muss separat in den App-Einstellungen eingerichtet werden.

Thunderbird

  1. Auf „Für Thunderbird herunterladen" klicken — es wird eine Datei eqx-signatur.html gespeichert.
  2. Die Datei an einen festen Ort ablegen (z. B. Dokumente/EQX-Signatur/) — Thunderbird liest sie bei jedem Start neu ein, sie darf also nicht verschoben oder gelöscht werden.
  3. Thunderbird öffnen → Menü „Extras" → „Konten-Einstellungen" (Windows/Linux) oder „Thunderbird" → „Einstellungen" → „Konten-Einstellungen" (macOS).
  4. Dein E-Mail-Konto in der linken Spalte auswählen.
  5. Haken bei „Eine Signatur-Datei anhängen (HTML, Text, Bild)" setzen.
  6. Auf „Durchsuchen…" klicken und die gespeicherte eqx-signatur.html auswählen.
  7. „OK" klicken — fertig.
